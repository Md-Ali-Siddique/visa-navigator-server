# Visa Navigator Server

REST API for the Visa Navigator portal, built with Express and MongoDB.

**Live API:** https://visa-navigator-server-bay.vercel.app

## Features

- Create, read, update and delete visas.
- Latest visas endpoint that returns the six newest entries.
- Filter visas by type and list the visas added by one user.
- Submit, search and cancel visa applications, with a duplicate-application check.
- Environment variables keep the MongoDB credentials private.
